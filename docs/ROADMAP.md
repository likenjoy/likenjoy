## 一、项目现状（已完成 ✅）

### 核心闭环（本地环境全链路验证通过）
```
展示 → 注册 → KYC(链上身份) → 资产发行(链上mint) → 认购
→ 交易(订单簿+Epoch批量结算) → 分红(RDT收益代币) → 赎回 → 收入入账
```

### 功能全景
| 模块 | 能力 |
|------|------|
| **合规层** | ERC-3643 全栈（身份/合规/白名单）、KYC 链上联动、专业投资者认证、锁定期双向约束、锁区 |
| **交易层** | 订单簿（限价/市价）、Epoch 两阶段批量结算（防抢跑）、免 Gas 元交易（EIP-2771）、转账手续费链上扣收 |
| **资产层** | 资产发行自动上链、净值/价格曲线（echarts）、收益累积代币 RDT（线性释放+按份额分配） |
| **收入层** | 铸造费、转账费（链上强制）、Gas 加价、广告位、收入/气/审计三账本 |
| **安全层** | JWT 环境变量+HS256+实时校验、限流 60/分、失败锁定 5次15分、nonce 锁+gas 估算、合约熔断 |
| **工程层** | Docker 单机部署、CI（GitHub Actions 三 job 全绿）、健康检查、备份脚本、主网检查清单 |

## 三、产品决策记录

### 决策 1：不做公开 AMM Swap（2026-08-05）
**结论：不做公开 AMM；做合规版流动性方案（P2）**

**原因：**
1. **技术硬冲突**：ERC-3643 合规代币每笔转账过 ComplianceModule，非白名单地址拒绝——公开 AMM 池（任意人兑换）无法通过合规检查（RealT/T-REX 生态无成熟 AMM 即此原因）
2. **监管红线**：自动做市+公开兑换属 7 号牌（ATS）范畴，超出 1/4/9 号牌路径；算法定价对证券代币的公平定价有合规疑虑
3. **客户匹配**：机构/家办要订单簿+OTC 大额报价，非 swap

**替代方案（P2）**：白名单流动性池（池子预白名单+兑换者须 KYC）、稳定币兑换窗口、OTC 接口

### 决策 2：测试网选型 Arbitrum Sepolia（2026-08-05）
- L2 gas 便宜（保住免 Gas 体验）、生态成熟、官方测试网活跃
- 主网候选：Arbitrum / Base（部署时按 gas/生态再定）

### 决策 3：私钥分级管理（已实现）
- RPC/CHAIN_ID 明文可编辑；JWT_SECRET 脱敏可轮换；ETH_PRIVATE_KEY 只换不看（写 .env 0600 + 审计）
