# RealVest — 合规 RWA 代币化交易所

> **一句话定位**：把真实世界资产（房地产、基金、贵金属、企业股权）代币化，让专业投资者通过合规链上通道认购、交易、收分红——香港 SFC 持牌路径下的机构级 RWA 平台。

---

## 🎯 解决的问题

传统资产代币化面临三座大山：**合规**（投资者身份与链上身份的绑定）、**流动性**（二级市场冷启动）、**信任**（资产真实性与分红透明）。RealVest 用一套完整的技术栈+合规设计同时解决三者。

## ✨ 核心亮点

### 1. 合规即代码（合规层）
- **ERC-3643（T-REX 官方标准）全栈**：身份注册 → 合规模块校验 → 白名单转账
- **KYC 与链上身份联动**：后台审核通过 → 自动链上 registerIdentity + 白名单
- **专业投资者认证**：香港 SFC 800 万港元门槛校验（文档+审核流）
- **锁定期双向约束 + 锁区**：防内幕交易与违规流通

### 2. 免 Gas 元交易（体验层）
- **EIP-2771 TrustedForwarder + 自建 Relayer**：投资者签名（EIP-712）即可转账，**平台代付 Gas**
- 六层校验：from 绑定钱包 / to 白名单 / value=0 / deadline / nonce / 验签 + GasRecord 记账

### 3. 防抢跑交易结算（市场层）
- **Epoch 两阶段结算**（参考 Centrifuge）：订单收集期 → 批量撮合，杜绝抢跑与时间博弈
- 订单簿 + Uniswap 式交易 UI + 资产双视图

### 4. 分红自动化（收益层）
- **RDT 收益代币**（参考 Maple）：资产方存入收益 → 线性释放 → 按持有份额自动分配，随时 claim
- 链上强制转账手续费（T-REX TransferFees，上限 10% 防异常配置）

### 5. 数据可视化（信任层）
- 资产净值/价格曲线（echarts 面积图）+ 工作台趋势卡
- 收入看板（铸造费/转账费/Gas 成本）+ 收入/气/审计三账本

### 6. 安全六层防线（安全层）
```
JWT 环境变量化+HS256+实时查库 → 限流 60/分
→ 失败锁定 5次15分(IP+邮箱双维度) → nonce锁+gas估算
→ 合约锁区+熔断 → 攻击模拟测试(暴力破解/越权/注入)
```

### 7. 收入模型（商业层）
| 收入项 | 说明 |
|--------|------|
| 铸造费 | 资产发行时链上扣收 |
| 转账手续费 | 每笔链上强制 0.5%（上限 10% 可配） |
| Gas 加价 | 免 Gas 服务的平台成本+利润 |
| 广告位 | Landing 轮播 + 后台管理 |
| 承销费/管理费（未来） | 发行承销 2-2.5% + AUM 0.5%/年 |
