# 主网部署上线检查清单（Mainnet Deployment Checklist）

> 适用：从测试网（Arbitrum Sepolia）迁移到主网（Arbitrum One / Base / Polygon）前逐项确认。
> 原则：**合约不审计不上主网；密钥不安全不上主网；监控不齐不上主网。**

## 一、合约安全（硬门槛）

- [ ] 1. 合约完成第三方审计（CertiK / SlowMist / 本地审计所），出具书面报告
- [ ] 2. 审计发现的问题全部修复并复测（合约测试 ≥ 31 项）
- [ ] 3. 主网部署使用**全新合约地址**（不复用测试网部署）
- [ ] 4. 部署后验证：owner/agent 权限、锁定期、国家锁区、熔断开关
- [ ] 5. 平台账户 gas 储备：主网原生代币（ETH/ARB）足够覆盖 100+ 笔代付交易

## 二、密钥与权限（硬门槛）

- [ ] 6. 🔑 JWT_SECRET 更换为生产强随机值（≥32 字符，与 dev 值不同）
- [ ] 7. 🔑 平台私钥更换为专用生成的新账户（与测试网账户隔离）
- [ ] 8. 🔑 私钥冷存储备份（离线保险箱），服务器仅存副本
- [ ] 9. ⚠️ 决策：平台私钥升级 Safe 多签（2/3 签名）后再上主网，或第一期单签+熔断兜底
- [ ] 10. CORS 白名单配置（仅允许生产域名）

## 三、基础设施

- [ ] 11. 香港 VPS（或合规云）部署，Docker compose 一键启动验证
- [ ] 12. 域名 + HTTPS 证书（nginx 配置验证）
- [ ] 13. RPC 节点：Infura/Alchemy 付费计划 + 备用节点（故障切换）
- [ ] 14. 数据库：SQLite 文件每日备份 + 异地存储（或迁移 PostgreSQL）
- [ ] 15. 监控：/api/health 定时探活（UptimeRobot/云监控）+ 链交易失败告警
- [ ] 16. 日志：结构化日志采集（服务重启后保留）

## 四、合规运营

- [ ] 17. KYC 审核流程演练（至少 3 个测试用户全流程）
- [ ] 18. 制裁名单筛查启用（Shufti Pro AML 或 OpenSanctions）
- [ ] 19. 费率表确认（铸造费/转账费/gas 加价/金库地址）
- [ ] 20. 披露文件：募集公告、风险提示、免责声明上线
- [ ] 21. 广告位内容合规审查（不涉及虚假宣传）

## 五、演练与灰度

- [ ] 22. 测试网完整演练：注册→KYC→认证→发行→认购→分红→赎回（全流程截图留档）
- [ ] 23. 模拟攻击演练：伪造 token、暴力破解、越权访问（scripts/ 6 套测试全绿）
- [ ] 24. 灰度策略：先开放 1-2 个资产 + 邀请制投资者，观察 1-2 周
- [ ] 25. 回滚预案：合约熔断开关 + 前端版本回滚 + 数据库备份恢复演练

## 六、上线后 24 小时观察

- [ ] 26. 链上交易成功率 100%（无签名错误/无 revert）
- [ ] 27. gas 成本与预期一致（relayer 记账核对）
- [ ] 28. 收入账本：铸造费/转账费正确入账金库
- [ ] 29. 无异常登录/爆破尝试（安全日志）
- [ ] 30. 投资者反馈通道畅通（客服邮箱/Telegram）
