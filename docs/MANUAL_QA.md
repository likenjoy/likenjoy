# 人工验收清单（Manual QA Checklist）

> 适用：上线前由真人（你/测试员）在浏览器 + 真实钱包（MetaMask）走一遍。
> 自动化测试覆盖 API/合约/页面渲染，但**钱包签名、浏览器交互**需要人工确认。

## 准备

- [ ] 1. 浏览器安装 MetaMask，导入测试钱包（本地链：添加 Hardhat 网络 chainId 31337 RPC http://localhost:8545）
- [ ] 2. 前端 `http://localhost:3000`、后端 `http://localhost:8080`、链 `http://localhost:8545` 全部运行
- [ ] 3. 准备两个测试账号（A=发行方/admin，B=投资者）

## 一、钱包连接（核心人工项）

- [ ] 4. 登录后右上角「Connect Wallet」→ MetaMask 弹窗 → 连接成功显示地址
- [ ] 5. 刷新页面钱包连接状态保持（RainbowKit 持久化）
- [ ] 6. 断开钱包 → 重新连接正常

## 二、钱包绑定（KYC 链上身份前置）

- [ ] 7. 个人中心/API：`POST /api/auth/bind-wallet`（钱包地址绑定账户）
- [ ] 8. 绑定后刷新，账户页显示已绑定钱包地址

## 三、免 Gas 转账（EIP-2771 签名）

- [ ] 9. 持仓页 → 点「免 Gas 转账」→ Drawer 打开（绿色 Banner 显示平台代付）
- [ ] 10. 输入接收方地址 + 数量 → 点确认 → **MetaMask 弹出 EIP-712 签名窗口**（显示转账详情，非交易确认）
- [ ] 11. 签名后自动上链，显示交易 hash；接收方余额增加（扣除手续费）
- [ ] 12. 取消签名 → 无任何链上变化
- [ ] 13. 接收方未 KYC/未绑定钱包 → 后端拒绝并提示

## 四、资产与交易

- [ ] 14. 发行方创建资产 → 自动上链 mint → 资产列表出现（网格卡片）
- [ ] 15. 资产详情页：净值曲线渲染（真实历史数据）
- [ ] 16. 交易页下单（买入/卖出）→ 创建结算周期 → 关闭并结算 → 订单状态变化
- [ ] 17. 分红计划创建 → 状态流转（发放中/已完成）

## 五、权限与安全抽查

- [ ] 18. 投资者访问 /admin/* 页面 → 无权限提示（前端路由守卫）
- [ ] 19. 错误密码连续 5 次 → 账户锁定 423 → 15 分钟后恢复
- [ ] 20. 双主题切换（顶栏🎨）→ 全站颜色变化且刷新保持
